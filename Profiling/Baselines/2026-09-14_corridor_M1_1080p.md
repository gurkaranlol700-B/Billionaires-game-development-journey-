# Baseline: corridor, M1, 1080p -- WITHOUT global illumination

Captured 2026-09-14. File: 2026-09-14_corridor_M1_1080p.csv

## IMPORTANT
Lumen was NOT rendering in this capture. The project config enabled
r.Lumen.HardwareRayTracing but never set r.RayTracing (plus the SM6 shader model)
or r.GenerateMeshDistanceFields, so Lumen had no way to trace and silently fell back
to SSAO + screen-space reflections. Do not compare a with-GI capture against these
numbers as if they were like-for-like.

## Conditions
- Standalone: UnrealEditor.exe Seawall.uproject -game -windowed -ResX=1920 -ResY=1080
- -csvCaptureFrames=2400 -csvGpuStats -ExecCmds="r.VSync 0, t.MaxFPS 0" (both confirmed applied)
- Editor closed during capture
- Scalability: Epic (all groups @3)
- RHI: D3D12, feature level SM5, raytracing=0
- View: PlayerStart (160, 0, 95) looking down corridor A, standing still
- First 600 frames discarded as warmup; 1801 frames analysed
- Hardware: RTX 5060 Ti 16 GB (driver 616.64), i5-14400F, 32 GB RAM
